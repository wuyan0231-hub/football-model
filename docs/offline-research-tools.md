# 独立离线研究与当前报价诊断入口

这些工具复用现有模型函数，独立保存输入身份、计算与验证结果。工具源码、合成测试和真实个案材料分别管理；本页不包含真实个案配置、来源标识或实验结果。运行者须提供获准的本地材料，不能把测试夹具当成真实研究协议。

| 入口 | 用途 | 本地输入 |
|---|---|---|
| `scripts/current_observation_decision.py` | 验读当前实际观察的整行参考报价，针对已核模型执行同合约支付计算 | `--runtime`、`--config`、比赛选择及 `--input` 个案输入 |
| `scripts/finalize_current_observation_decision.py` | 验证已有当前诊断调用及其人工决定链接，再独立编译并核验决定记录 | `--run-dir`、`--run-receipt-sha256`、`--source-root` 及 `--link-input` |
| `scripts/restricted_start_development.py` | 用既定历史候选池进行分阶段首发边际概率开发、选参、校准及测试 | `--inventory`、`--protocol` 及 `--before-fit-freeze` |
| `scripts/cold_start_past_masking.py` | 先审查过去球队完整删除的训练资格，再按显式协议执行独立父拟合与参数不确定性诊断 | `--source`、`--protocol`；仅检查计划时另加 `--inventory-only` |

每次通过 `--output` 指定新输出位置。真实研究协议由运行者用 `--protocol` 显式传入本地私有配置；真实个案输入、拟合前冻结记录、原始资料和详细结果不随这些公开工具发布。可先查看各脚本的 `--help`，再使用获准输入运行。

当前观察入口保留未知的报价变化时间，只按真实看到的合格整行提供参考计算。读取时间不能替代变盘时间；参考报价也不认证当前开放、可成交或历史截点资格。费用未知时净 EV 保持未知，不把毛 EV 排序当成人工决定或交易指令。历史截点报价的原时间门继续独立执行。

决定记录的后续编译保留原调用、原人工决定和它们各自的真实时钟。编译与验证时刻另外记录，不能回写成原分析、原报价或赛前保存时刻；失败与旧输出保留，更新另存。

两项研究都保留缺失、失败、样本不足、隔离排除及合法回退分母。首发边际概率不等于完整首发阵容的联合分布；过去删除实验与概率矩阵数值复算不证明未知球队的未来校准。运行和测试成功不表示候选有效或已采用生产。

`tests/fixtures/` 中新增的两份 `*-synthetic-protocol-v1.json` 仅供单元测试，包含合成来源标识及占位哈希，保留待测算法门槛。它们不包含真实来源资料，也不是实际实验协议或可用的研究授权。真实协议与结果保留在本地原身份下，不因公开合成夹具而改写。
