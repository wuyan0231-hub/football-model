# S2：旧模型真实拟合完成时间迁移

状态：已实现并完成本地工程验证；未据此宣称生产已部署、线上已迁移或准确率提升。

本改动处理兼容性审查 P0：旧模型数据未变、尚未超龄、未来窗口有赛程，但 `model_fitted_at` 缺失时，原更新逻辑沿用旧模型，严格前瞻协议随后拒绝。它不改变算法、训练超参数、训练输入指纹、固定时间留出或任何前瞻时间门禁。

## 执行政策

`process_competition` 在训练模式下增加独立原因 `missing_model_fitted_at`：已存在模型、有未来窗口赛程，并且字段不存在或为 `null`，就走完整的原验证及拟合流程。已知但格式错误的时间继续明确失败，不将其当作可以猜填的时间。只做数据审计时不触发迁移。

1. 先将旧模型的完整原字节按 SHA-256 保存到 `runtime/model_history/<赛事>/predecessors/<sha256>.json`；先写临时文件，再原子发布，不覆盖已有副本。已有同指纹路径内容不一致则停止。
2. 保留原 `evaluate_time_holdout`；合格测试比赛数不足时停止，不绕过验证。
3. 在真实新截点调用原 `fit_model`；参数边界检查照旧。新 `model_fitted_at` 来自拟合完成后的真实时钟，不复制旧 `trained_at`、文件修改时间或报告时间。
4. 新模型与运行报告保存迁移原因、旧模型 ID、前驱文件指纹、真实新拟合时间。保存新版本与验证后才替换当前模型。
5. 拟合/验证/保存失败时保留旧模型原字节，记录 `time_evidence_migration.status=failed`、具体阶段和原因，不用旧模型伪装新预测。其他联赛可继续保存自己的局部成功。
6. 无未来赛程时不因为字段缺失额外训练；完成迁移后，输入仍未变化且未触发其他刷新原因的后续运行继续沿用参数。

现有年龄门禁仍按 `training_cutoff` 检查本次运行和开球时；不因字段迁移放行超出预测有效期的票。国家队与国内联赛共用此迁移入口，欧国联的场地/中立场准入保持原样。

旧报告、旧预测、旧前瞻拒绝和旧模型历史均不修改。新证据不能使旧预测取得原来没有的赛前资格。本政策用于补齐真实新模型的证据，不是仅因旧时间显示格式升级而强制重训。
