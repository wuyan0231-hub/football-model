## 计算口径

旧`score_cold_start`先生成同一冻结父模型的点先验，已知对手参数保持原样。τ=0或全部相关方差为0时，`prediction`逐对象原样返回旧函数结果，包括原矩阵，不走近似求积。

正τ首版只给未知队的攻击A、防守D设置独立正态潜在值。参数输入的两个参考方差分别乘τ²，记为vA、vD：

- `E[A]=−vA/2`，`E[D]=+vD/2`。
- 由于防守在原进球公式中取负号，`E[exp(A)]=E[exp(−D)]=1`，边际平均进球率保持点先验λ。
- 主队log λ随机项为未知主队A减未知客队D，方差为相关两项方差之和；客队反之。
- 全部未知A／D在队内和跨队均独立，因此两边使用的潜在变量不重叠；可分别进行一维泊松—lognormal边缘求积，再取外积。这一化简不适用于非零攻防相关、跨队相关或共同已知参数误差，输入这些要求会明确拒绝。

计算器混合概率分布，不使用“平均λ再生成泊松”。正τ在固定λ平均值之外增加分布离散度；未知队个体实力没有因此被学到。已知对手、截距、主场项的估计误差也尚未积分。

## 数值、尾部与失败

节点阶梯固定为12、20、32、48、64、96、128。至少两次连续阶数的边缘L1差及求积平均率误差都达标，才允许输出；GH差只是收敛诊断，不冒称严格的全局积分误差上界。

格点尾另有独立分布界。对任意正数L：

`P(G>K) ≤ P(λ>L) + Poisson.sf(K,L)`。

L由lognormal上分位选取，只用于尾界，**不裁剪节点λ或先验**。按上述界扩展K，同时保存先验上尾、条件泊松尾、原始边缘、原矩阵质量及节点诊断。只有尾界和收敛均通过后才明确归一；解析平均率与有限归一矩阵的平均率分别报告。若浮点矩阵质量略大于1，概率尾字段只将负舍入置0，原有符号差仍保留在诊断。

首版工程范围为log率方差不超过1、每边最多512球的演示格点；设置可收紧，代码硬限最多1024。过宽、超资源、非法参数、相关性、未收敛、父哈希失配均明确失败，不封顶λ、删极端情景或把失败当0分。
