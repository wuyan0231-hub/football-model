# F4 数据准入与所见样本诊断

本模块是离线研究工具，不由每日任务自动调用，不联网、不改生产概率、模型或原始响应。它补足球员分钟语义与队级数据代表性检查；已有的有效首发／未知替补、加时过程统计隔离和射门闭合检查继续复用 `fundamentals.py`。

## 执行入口

```bash
python -m football_model.f4_data_quality \
  --fundamentals-dir /path/to/fixed/runtime/fundamentals \
  --probe-dir /path/to/S1/API/live_results \
  --data-dir /path/to/fixed/runtime/data \
  --as-of 2026-10-07T09:54:42Z \
  --output /new/research/path/observed_data_quality.json
```

三个输入目录可单独指定，至少需要一个；输出必须不存在，不能覆盖旧报告。扫描范围只限指定目录：`fixtures/*/*.json`、S1 指定原响应及传输清单、`data/*.json`。每个原文件记录完整字节 SHA-256；F3 继承的 fixture 保存件核对内容地址，S1 原响应核对传输清单里的保存字节哈希。欧冠数据明确标记 `audit_only`，不能当作生产拟合联赛。

`as_of` 是诊断边界，不是历史前瞻授权。基本面只选该边界内真实取得的最新版本；同一比赛重复观察不重复计数，同一时刻冲突停止比较。事后取得的历史资料仍标记 `historical_prematch_availability_verified=false`，不倒填历史前瞻资格。

## 分钟准入

| 原字段及证据 | 保存与处理 |
|---|---|
| 字段缺失、`null`、数值 `0` | 分别标记 absent/null/reported_zero，互不转换 |
| 终场首发或换人参与者，分钟为空 | 已出场有依据，分钟仍缺失，不补0 |
| 替补名单、无换人记录、分钟0/null | 保留未知，不能单凭未见事件认定未出场 |
| FT中正整数1—90分钟，球员ID有效且不重复 | 保留“供应商报告分钟候选”，仍不宣称精确常规时间暴露已验证 |
| FT分钟大于90 | 保留原值，隔离分钟特征，不截成90，也不自动认定加时 |
| AET/PEN、未完赛、未来比赛 | 不准入常规时间分钟候选；未来首发不是实际出场证据 |
| 球员统计ID为0/null、重复球员、异常球队块 | 保留或记录原位置，隔离相关人员特征；不制造ID，不影响有效首发和球队xG |

`player_statistics.present` 只代表有球员统计行。`candidate_usable` 必须至少有一条合格的供应商报告分钟；另有 `player_minutes` 与 `player_identity` 的独立覆盖。全是空分钟／未知ID的外壳不会算成可用人员数据。有效首发与未知替补继续由原规范化器分别保留。

异常的球员、事件模块只局部隔离；有效xG、首发与该比赛的分母仍保留。异常射门原值不修补，依赖该字段的候选另外隔离。取得数值xG不意味着射门矛盾能被忽略，也不因射门矛盾自动认定xG错误。

## 字段覆盖与代表性

按联赛、赛季、球队分别给出字段存在、缺失原因和候选可用数。分母明确是**提供给本次检查的球队—比赛样本**，不是全联赛比赛；选择偏差标记保持true。未来比赛的空外壳也保留在所见样本分母，不能拿它当历史供应商覆盖率。

训练数据另逐队报告最近比赛、30/90/180/365日场数、最近5场、基本面与训练比赛身份匹配的交集。最新的联赛比赛不能掩盖某些球队很久没有比赛；文件更新和采集日志日期不能证明队级数据新鲜。90日无比赛只是描述，降级、赛制和休赛均可能造成这一现象，不能自动判定抓取失败。全赛事负荷、完整赛程总体和真实历史可见性均保留未验证。

比分文件的4小时赛果成熟规则复用原研究约定；它不是实际赛果取得时间。如果文件本身在截点后取得，报告明确标记，绝不升级为历史真实快照。基本面交集必须同时匹配比赛ID、主客队与开赛时间。

## 2026-10-07 实际诊断

固定数据来源为本轮已校验的 model-state 原件与 S1 已保存原响应。诊断截点为北京时间 **2026-10-07 17:54:42**；没有新增API请求。

- 294次 fixture 观察去重为 **141场**，153次重复／旧版本不算独立比赛。119场FT、18场NS、3场PEN、1场AET。
- 5627条球员统计：3870条正分钟、1642条null、115条0，全部保持不同状态。
- 6场含 **7条球员统计ID=0**。这些行隔离人员身份和分钟特征，有效球队xG与首发保留。两名首发完整但替补ID未知的原记录继续保留。
- **208条FT分钟大于90**，原值不裁切，等待供应商分钟定义与事件核查；4场AET/PEN的190条球员统计不能直接用作常规时间暴露。
- 复用射门闭合诊断得到4条所见矛盾；未提供半场细项的资料不能声称半场闭合已验证。

下表是与提供的常规比分数据实际匹配的交集，**不是供应商完整覆盖率**：

| 联赛 | 本次比分文件场数 | 匹配到过程样本 | 双方有可用常规时间xG的比赛 |
|---|---:|---:|---:|
| 巴甲 | 1039 | 49 | 44 |
| 欧国联 | 434 | 78 | 20 |
| 阿甲 | 1307 | 4 | 1 |
| 西乙 | 1024 | 4 | 0 |

巴甲在已观察的2026样本53场／106队场中，84队场有数值xG；2024、2025各仅观察1场，不可由此认定跨季连续完整。欧国联2024观察46场的92队场均为xG空值；2026观察31场中40／62队场有数值。阿甲2025抽样有数值xG但为加时／点球口径，未授予常规时间特征资格；西乙当前所见各赛季仍无数值xG。

所有19份比分文件的真实 `observed_at` 均在10月7日；18个生产配置赛事中，11个的最新保存比赛仍在9月19—20日。该结果表明不能只看文件日期推断当前球队信息，**并不证明这11个联赛有遗漏比赛**；要证明遗漏仍需独立完整赛程对照。欧冠另作审计。

因此当前准入决定是：**继续比分模型的滚动研究；人员和xG模型尚不能进入正式概率**。巴甲值得优先扩大有代表性的历史连续覆盖检查；欧国联需显式处理跨赛季xG缺失。不能拿少量抽样存在数值来批准新变量训练或称准确率提高。

## 验证

```bash
python -m unittest tests.test_f4_data_quality -q
```

21项针对性测试覆盖null/0/缺字段、未出场未知、未来首发、加时和FT大于90、未知身份、重复球员／球队、异常模块局部隔离、原值不改、重复观察分母、真实时间边界、源文件哈希与队级近期性。工程测试证明边界行为，预测增量需另行滚动和前瞻验证。
