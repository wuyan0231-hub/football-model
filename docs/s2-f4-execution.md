## 已执行的首轮历史实验

源码基点 `ece3400d230b8728a7d0a81c21ffc7b1dfacfd61`，数据状态 `c27ebc3672c6b3e43768921fba8a0084d91a4144`。执行前冻结总协议与每赛事协议；运行代码及每份输入原字节另记指纹。

- 18个独立赛事，欧冠仅审计，不参加模型试验。
- 外层区间2025-10-07 00:00Z至2026-10-07 00:00Z，按7天原点滚动拟合。
- 候选半衰期90、180、365天；180为控制，ridge=3，最小训练180场。
- 每个原点只用此前已成熟赛果，选择器仅用此前180天共同覆盖的预测损失，至少40场，不足回退180。
- 主比较为“仅用过去资料选择半衰期”的策略对180，主指标为完整1X2概率空间的Log loss，越低越好。
- 外层5854场，共同覆盖5802场；15次实际拟合因图断连拒绝，另24次训练不足未调用拟合。全部缺口保留。

结果：5赛事主损失点估计下降、13赛事上升，没有一个赛事的描述区间整体低于0。欧国联只有88场与3个时间块，不提供区间。90天固定候选整体表现较差，365天在不同指标上有混合结果。保留生产180天，不晋级自动选参，也不从次级指标或联赛事后挑赢家。

本轮是当前已修订历史数据的开发研究，不是当时逐日生产记录重放。28天分块bootstrap只提供开发描述，未做跨赛事多重比较校正。每周重拟合控制不等于原生产固定留出。固定ridge下改变半衰期同时改变总加权似然规模与相对收缩，不能将差异单独归因于“更重视近期”。细节与命令见 [半衰期研究](s2-f4-half-life-research.md)。

## 框架选票与模型效果分开

[独立选票对照](s2-independent-decision-trials.md)提供register/open/submit/compare。两侧从同一中立F2输入包，按各自冻结政策实际独立分析，允许选不同主方向；必须保存两份真实输出。相同模型下的1X2概率分数通常相同，换票效果应看共同机会上的政策结果，不能把不同票五态Brier直接相减。

本批接口测试与合成案例不构成真实GPT政策效果样本。目前没有新生成的两份真实独立政策决定，不能用176场模型对照替代它们。新比赛请求到来时使用该入口，保存全部失败、弃权及缺件；不编造旧判断或成交记录。

## 接下来如何判断

1. 本轮自动选参候选不晋级，正式模型维持180天。历史研究文件封存，不随新结果改写。
2. 已接入的未来管线继续留存真实预测及赛果，日更仅作描述与完整性检查，不每天检查直到显著。收益没有实际同机会价格、费用及决定时保持未评估。
3. F5正式效力验收须在开启一批未观察赛果的样本前，冻结候选、主指标、请求/比赛全集规则、时间块、样本量或固定结束日期、多重比较、缺失处置及晋级/停止条件。原协议中的0.01平均Log loss下降只是最小有意义效果，不等于已完成统计功效设计或已达门槛。
4. 当前影子批次用于前瞻积累与开发验证；不追认成尚未冻结的F5确认性试验。若需要据新研究更换候选，另建版本与新批次，不回写现有90主比较。

F4首轮执行完成与“模型/框架准确率或收益提升”是不同结论。本批获得了可复核的负结果和可持续前瞻记录；效果仍须由后续真实数据证明。
