# S2开测协议：实际原件冻结、独立任务和确认准备

本文件提供可执行准备入口，**没有生成两份实际分析，也没有激活F5确认**。现行正式四态判断、180天生产模型、日程和全部旧协议不因本轮准备改变。

## 两条试验分开

| 项目 | 框架政策包对照 | F5模型确认准备v2 |
|---|---|---|
| 唯一干预 | 左：上传v1.7r4＋图规v1.2r4完整原文；右：本次固定v1.7r5＋图规r5＋已验收输出/开测入口 | 同一真实每日180天预测上的固定总球收缩政策 |
| 共同控制 | 同比赛、任务、实际截点、中立事实和完整报价池、原比分矩阵、公共读盘转换/结算工具、GPT版本及可取得的参数 | 同一生产父预测、同训练集合均值、原泊松函数、真实独立赛果成熟链 |
| 主对象 | 首批流程试运行；参考价策略单位收益仅描述 | 真实未来总球Log loss质量；没有ROI/实盘目标 |
| 当前状态 | 准备稿和双侧独立任务模板；实际请求和双判断为0 | 准备稿；影子仍全部`confirmation_eligible=false` |

框架包包含多条规则变化，整体包是唯一政策干预，**不能据此归因到某条规则**。单项消融另建版本。对照使用共同已核中立报价整行；两侧使用同版本报价转换/结算，不将移植旧读盘错误宣传为新政策的效果。真实OCR能力另用盲测原图，核定真值不进入分析者上下文。

## 先封存实际政策全文

`football_model.pretest_protocols`不联网、不拟合、不运行GPT，也不把哈希当来源认证。`freeze`逐一保存双方实际完整原字节及声明的源码/规范，生成：

- `preparation.json`：准备稿、真实冻结时刻、源码声明和全部原件摘要；
- `originals/`：内容寻址原件，原文不变；
- `policies/left.json`、`policies/right.json`：不同政策身份及完整原件绑定；
- `tasks/left.json`、`tasks/right.json`：独立执行模板，尚无比赛、共同池或输出；
- `manifest.json`：全部文件清单；返回的SHA必须单独保存作为外部锚点。

```bash
python -m football_model.pretest_protocols freeze --protocol docs/research/s2-framework-comparison-prepared-v1.json --source-root . --source-commit ACTUAL_FULL_SOURCE_SHA --left-framework UPLOADED_R4_FRAMEWORK_PATH --left-odds UPLOADED_R4_ODDS_PATH --output NEW_FROZEN_POLICY_DIRECTORY
python -m football_model.pretest_protocols verify --frozen-root NEW_FROZEN_POLICY_DIRECTORY --manifest-sha256 ACTUAL_MANIFEST_SHA --output NEW_VERIFY_RECEIPT.json
```

参数中的大写是占位符，不是已执行证据。右侧源码/规范仍在编辑时不能声称封存包已绑定最终发布树；**最终发布前后固定版本，重建新封存包并核其原件与真正部署提交**。原包保留。源码SHA标签只标声明的发布/祖先，不会自动证明工作树与该提交完全一致。

## 到真实新请求再登记，不补造比赛

`requests`命令调用现有`decision_scoring.register_scoring_protocol`与`decision_trials.register_trial`，生成兼容现schema的登记。请求需要真实比赛ID、双方ID、未来分析截点和开赛时间；共同任务须与准备稿完全一致。已过截点、历史赛后或试运行不能倒填为前瞻。

```bash
python -m football_model.pretest_protocols requests --frozen-root FROZEN_POLICY_DIRECTORY --manifest-sha256 ACTUAL_MANIFEST_SHA --requests ACTUAL_FUTURE_REQUESTS.json --trial-root runtime/decision_trials --output NEW_REGISTRATION_RECEIPT.json
```

真实截点必须选在登记后，例如请求到达后，先登记将要冻结的资料截点，再取得共同事实，关闭资料窗口。它不同于请求时间或最终报告时间。只登记模板、空请求和复制历史决定均不能得到实际对照。

后续由[现有独立对照入口](s2-independent-decision-trials.md)执行：

1. 冻结一份**没有主票、没有候选、没有旧分析**的真实F2中立证据包；模型、报价全行、实际取得时间和完整父链两侧相同。`open`返回真实机会清单SHA。
2. 在两个全新隔离上下文中，只分别发该侧完整政策原件与共同池；不传聊天历史、另一侧答案、赛果、OCR标准答案。记录实际运行系统、模型/参数、上下文身份、输入包摘要和暴露状态；无法取得的属性保持未知。
3. 原始首输出立即留存并`submit`；首失败、半成品失败槽、明确弃权、条件未决、缺件均保留。后来重试追加，不替换主要比较的首输出。不用多数票选方向。
4. 旧版输出只映射实际写明的字段；完整原始文字先保存。新版缺失也不能补造。规则输入使用已登记的`policies/{side}.json`作为政策定义；其底层全文由外部封存包原件和SHA绑定。共同工具与事实引用使用共同池，不把新事实伪装为代码或规则。
5. 赛后用同一独立、核定的90分钟＋补时赛果版本评分；同比赛的更新、市场和重试不增加独立比赛数。源记录、决定、事件、比分修订和结算全部追加。

单关主目标使用`QUOTE_REF`、每机会一单位和**明确零费用的参考价纸面定义**；这不证明真实费用为0、报价开放或已成交。真实主动弃权在此定义下可为0敞口；未知、失败和未满足条件不是0。另报每下注ROI及其不同分母。`QUOTE_OPEN`和`QUOTE_ACTUAL`需各自完整证据与新协议；实际交易是观察性，不自动形成受控策略差。

框架首批固定连续30个请求机会，或未来起点后90天，先到即封组；不是凑30个成功配对。只在固定节点做一次描述报告，已入组赛果可等待14天。30场只诊断流程。有效性/盈利确认另需事前功效、时间依赖和新样本协议，不能将这30场追认。

## 影子等级和OCR真值隔离

正式仍为“适合／条件适合／不建议／暂无法判断”。A/B/C/D/U保持另有版本的影子；A/B也能只观察，待条件状态等级为空。单关与候选串关腿分别说明目标和普通分支风险，不能机械降级；不能推断整串收益，也不绑定固定胜率或EV。A级价值目标的原始胜率不必高于低价B，需按目标分别评价。

真实OCR基准需按比赛＋图SHA先分开发/验收，同场裁剪、不同版本不得跨组。人工核定完整整行、符号、盘口、状态、时间和赔率制式；有争议保留并裁决。独立读图只拿原图，真值与赛果由另一个评分角色保管。旧40场、六例回归、合成测试、第二遍回图、多次同答案均不是干净基准成绩。本轮没有真实新图，故错误率尚未得到验收。

## F5确认准备v2修正了什么

原`docs/research/s2-f5c-confirmation-prepared-v1.json`不变，v2另存。候选公式、五档α、180天选参窗、40场门槛、首次赛果真实取得且保存后48小时、主客比例与生产父件均保持。

| 条件 | v2事前固定方式 |
|---|---|
| 入组目标 | 10000个合法唯一基线机会，只作最低计数目标；按10%规划损耗为9000有效对留余量，不承诺损耗率或功效 |
| 正常封组 | 首个预定每日节点同时达到10000机会和365天；计数早到继续完整入组至365天，时间早到继续至计数到或硬截止 |
| 硬截止 | 实际激活后548天；不因有效评分数或观察效果延长 |
| 配对支持 | 至少9000个有核定FT的真实独立配对、365天、13个完整非空不重叠28天块；不足仍为证据不足 |
| 赛果等待 | 封组后固定14天，期间不新增机会、不改参数、不做第二次择优成功检查 |
| 取消／中止 | 无核定常规结果的预声明void单列，不评分；不是每次取消都必然使整试验失败 |
| 未解决赛果 | 最终不超过入组的1%；不补0，不用成功补招。推断只限有核定常规结果的群体，不能无证推广到缺失机会 |
| 候选捕获 | 主要已核定FT群体须全有真实开赛前候选或预先保存的α0回退和远端回执；缺候选则主要成功受阻，子集结果仅描述 |

10000是**最低目标而非容量上限**，365天前继续纳入可能超过10000。必须用548天完整机会流、版本增长、父证据/赛果修订、保存预留和无损恢复实测编制容量预算。当前快照成功保存不证明长期可行。

主指标和门槛不放宽：总球Log loss点差≤−0.01、保守95%上界<0；大2.5 Brier点差和上界≤0；1X2 Log loss点差和上界≤＋0.005；等赛事敏感性≤0及全部18赛事披露。开发筛选的四项原门槛也原样保存。9000来自历史候选SD0.167573、假设改善0.01、单次单侧α0.025、80%功效、设计效应4约8817的规划；不是80%成功保证。13个时间块仍有限，跨块/球队/赛季依赖未被证明消除。确认至少改善0.01仍需上界≤−0.01，不能把点差达到目标升级为该结论。

对缺失须披露分层率、已有基线分布及有限不利情景（缺失均值差＋0.1/＋0.25/＋0.5）。泊松Log loss无界，这些情景不是数学最坏界，也不是补写主指标；来源连续性、缺失机制或依赖不明时保留影子和证据不足，不晋级。

## 激活门禁目前保持阻断

```bash
python -m football_model.pretest_protocols freeze --protocol docs/research/s2-f5c-confirmation-prepared-v2.json --source-root . --source-commit ACTUAL_FULL_SOURCE_SHA --output NEW_F5_PREPARATION_DIRECTORY
python -m football_model.pretest_protocols check-activation --frozen-root F5_PREPARATION_DIRECTORY --manifest-sha256 ACTUAL_MANIFEST_SHA --request ACTUAL_ACTIVATION_REQUEST.json --evidence-root ACTUAL_REVIEW_ROOT --output NEW_GATE_RECEIPT.json
```

`check-activation`须有真实未来`start_at`、部署源码提交、准备清单SHA、`pilot_reclassification=false`、`backfilled_samples=0`，以及四种复核回执：部署源绑定、真实赛后评分＋48小时成熟链、548天容量与恢复、确认捕获/资格接线验收。四项必需门禁不能删除、清空或重复；每份回执必须绑定该准备包和源码、复核人/时间、真实原件路径＋SHA＋已保存时间。计数必须为非布尔整数。真实成熟链至少包括一场实际评分、一场实际已满48小时成熟、五档复算和比分修订追加验证；工程合成记录不得冒充真实比赛。

检查器核字节和复核声明，不能自动认证来源或思维独立。声明完整最多返回`review_declarations_complete_needs_independent_activation_review`，不表示真实成熟链、容量或激活条件已核定；仍须独立读取typed真实评分、结果、选择池、持久提交和预算恢复回执。检查器**不改变生产、不注册样本、不重标先导**；核定后还需另存真实不可变激活登记并用已验收的确认捕获资格模块消费。当前捕获模块仍是pilot，真实成熟和长期预算尚未闭环，不能用准备稿、冻结、成功先导或手填过去起点绕过。

技术硬错误修复保留失败并另版本。改变预测、选参、评分、纳入或停止条件须封存旧尝试，另立协议和未来队列；只有经逐原件证明结果不变的读取修复才可延续既存制品。MLS专项维持独立v2研究，不插入本确认政策。
