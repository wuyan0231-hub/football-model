## 新旧研究身份

现行高级协议为 `advanced-models-domestic-v1.json`，独立 `protocol_id` 与命名空间记录本次范围变更，包含12个offset分支及3个goalmodel的双时距，即每国内联赛18个组合、18联赛324个组合。原 `advanced-models-v1.json`、旧确认准备、原19赛事380组合及1900指标保持原字节身份；新协议继续使用至少380组合及1900指标的保守校正下限。旧失败不删除，不能通过缩小家族重算为通过。

已保存历史研究的18个国内联赛报告有限算术复算已经验读；原18国内360项开发门均未达到采用条件。原360项包括现行已退役的36个负荷组合。保留的324项在旧实现中的结果仍属拒绝，不能因范围变更转为合格或说成新协议研究已验收。生产保留M0，正式未来确认未激活。新源码、实现指纹、输入新鲜度、研究原件、真实持久保存和新未来资格仍分别核验，不使用修改环境变量、改标识或重贴旧卡的方式继承资格。

180天仍是生产历史权重的半衰期，不是最近180天硬截断窗口。statsmodels使用过去样本外M0的logλ固定offset；goalmodel作为独立对照。xG、射门代理、提前阵容、确认首发、已报告缺阵和完整球员能力各按自身资料和训练资格说明，轻量代理不代表完整能力或伤病严重程度模型。panna依用户决定继续暂停。

## 结案口径

原六项目标及完整人员、冷启动、独立选票和收益边界继续逐项报告。每项至少分别给出代码、测试、部署、真实运行、保存／恢复／回读、数据阻断、未来待办、效果和生产是否采用。可接受的研究结论包括明确拒绝；拒绝不能写成准确率提升。

| 状态 | 所需证据与下一步 |
|---|---|
| 工程完成 | 对应代码及实际测试、发布、运行和适用保存／回读回执 |
| 开发拒绝 | 完整候选和失败分母、原门槛、真实算术及来源，不反复重跑至显著 |
| 数据阻断 | 缺字段／资料合同／覆盖及其数量，不估造球员、xG或伤停真值 |
| 尚待未来 | 真实新起点、合法首次快照及未来成熟结果，不能以历史回放代替 |
| 不适用／主动暂停 | 用户范围变更或前置门未过的具体原因，不能冒充已执行成功 |

没有合法本场报价、原图、费用边界和完整决定时，不制造验收票；没有两份隔离上下文的真实独立首输出，不认证选票政策效果；没有实际交易，不报告实盘ROI。尚未发生的比赛和可靠预计首发概率不因工程结案自动补齐。
