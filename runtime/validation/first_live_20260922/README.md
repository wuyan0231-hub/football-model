## 历史验证结果

使用 API 实际取得的英超 2024/25 赛季：380 个唯一比赛 ID、20 支球队，每队 38 场（19 主、19 客）。该检查确认已下载数据符合双循环比赛数量结构，并不替代逐条对照另一家数据源。

按 UTC 日期切分：2025-04-06 00:00 前符合赛果可用条件的 304 场用于训练；随后 76 场用于检验。训练样本与检验样本没有重叠。赛果可用时间采用开球后 4 小时的保守假设，并非供应商历史发布时间。

|概率评分，数值越低越好|球队攻防模型|联赛主客均值基准|
|---|---:|---:|
|Log loss|0.9964|1.0745|
|Brier score（三分类平方误差和）|0.6014|0.6512|
|已评分比赛|76|76|

本次历史区间内，球队攻防模型优于简单均值基准。没有置信区间、多个赛季滚动验证或独立前瞻结果，因此不能据此宣称长期预测优势或盈利。半衰期 180 天、正则化强度 3 等参数沿用预先固定默认值，没有按这 76 场结果调参。

两次拟合均收敛，参数没有触及预设优化边界。完整赛季模型覆盖 20 支球队，但它只描述截至 2025-05-26 的历史数据，不能代表当前球队实力。
